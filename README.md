# Промт-библиотека Caviar

Личная полная копия конструктора с https://teatromisterio.github.io/prompt-catalog/.

Сайт: https://stoliarovd-mitrey.github.io/prompt-catalog/

Сохранены исходные HTML, CSS, JavaScript, 19 шаблонов, 140 опций конструктора и все 137 изображений. Внешняя зависимость: Google Fonts (Nunito Sans).

Для запуска достаточно статического HTTP-сервера или GitHub Pages из ветки main, каталога / (root).

## Ракурсы по референсам

Отдельный раздел: https://stoliarovd-mitrey.github.io/prompt-catalog/#angles/01

10 постоянных номеров, оригиналы изображений в references/, промпты в prompts/. Номера 01–09 соответствуют исходным именам фото, 10 — каталожный PNG.

Можно загрузить локальное фото нового устройства и скачать ZIP с референсом A, изображением B и промптом. Фото B не отправляется на сервер. Описание устройства сохраняется в localStorage браузера.

Для точного воспроизведения сцены нужен image-to-image генератор с двумя референсами; текст не гарантирует пиксельного совпадения. №02 — упаковка, №03/04 — складной корпус, №10 — PNG с альфа-каналом.
